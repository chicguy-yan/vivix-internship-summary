# ADR-0002 · 真实 case 复原与落位

- **日期**：2026-08-05
- **状态**：已接受（待执行）
- **影响**：§3 §4 §5 全部；作废 v3 稿里虚构的「校园悬疑女主」
- **依据**：实验 0002-refskill-ab（S001–S005）、实验 0006-ablation（R001–R010）

---

## 背景

v3 稿的 §5 用的是一个虚构 case（校园悬疑女主）。而实验详录里有 **10 个真实 case**，带完整 identity block、style token、check 点清单和真实翻车记录。用虚构 case 讲真事，等于把自己最硬的部分让掉了。

同时暴露一个更大的问题：**§3 §4 现在是纯方法论叙述，没有 case 支撑**。读者读完知道「有四类信息」「跑了三路对照」，但不知道这些判断具体作用在什么东西上。ADR-0001 的 D3 只规划了 4 张图，不够——每一条抽象原则都该有一个真实 case 落地。

## D3 · 落位：每条抽象原则配一个真实 case

### §3 工程链路 —— 四类信息，每类一个 case

现在四类信息只有解释没有例子。每类挂一个真实 case，读者立刻知道这个分类是从哪儿长出来的。

| 类别 | 挂哪个 case | 挂什么内容 |
|---|---|---|
| **连续视觉量** | BEAR-01 | 暖奶白毛被 `white`×6 洗成冷白瓷面。一句话带过，详细留给 §5 |
| **离散身份量** | J-01 机器人 | 4 条 check 点原文：`屏幕脸易被渲成人脸 / salmon 做旧红易调蓝翻新 / 机械材质 / 笑脸图形＝换屏幕图形非肌肉`。**最后一条最能说明问题——它锁的是改变的机制，不是外观** |
| **关系量** | 赛车手 | 2 变体 × 3 动作（跑 / 持枪 / 坐车头）。人与道具的接触点、人与车的空间关系 |
| **工程一致性** | MV 女主 | 1 身份 × 4 look 的复杂版式，两个模型都照做 → 说明版式靠脚本锁得住 |

**新增一小块**：check 点的挑选标准。原文是「**选会漂的，不选最好认的，没堆到 >5 条**」——这句话比整段方法论都有用，单独提出来。

### §4 怎么验证 —— 补两块现在完全没有的内容

**① 纵向三版**：挂 BEAR-01 全程。v1 堆描述 → 洗白 → 归因到 `white`×6 → v4 色词只标 hue + 反洗白守护句 → 毛色保住但徽章残留类文字痕。

**② 横向三路**：挂 R002（洗白熊）+ R008（用户超长 brief）。记录里这两个是 **pilot 先行**跑的，理由是「一个验证不洗白 + img2img 链路，一个验证边际增益的硬骨头」——这个选样理由本身要写出来。

**③ 跨模型对比 —— 页面上目前完全没有，但这是最硬的一条已验证结论。**

同一套 v4 提示词逐字相同（已 diff 验证），唯一变量换生图底模（Pro vs 基础版）：

- 防洗白色彩纪律：两个模型上**都成立**
- 单 hub 锚定 + 多面板版式合规：两个模型上**都成立**
- 差的只是渲染质量：分辨率、跨面板身份稳定、表情区分度、logo 可读、动作解剖
- 一个模型专属翻车：基础版把 J-01 的白笑脸屏渲成了**相机镜头**

结论一句话：**这是 prompt 工程的胜利，不是模型红利。** 换个便宜模型，掉的是画质，不是设计有效性。

> 这条必须进页面。它回答的是面试官一定会问的那句「你怎么知道不是模型本身变好了」。

**④ R008 —— 一个我设计来可能证伪自己的实验。**

用户自写超长 art-book brief，baseline 本身就很强。而且用户明确要「不对称身份板、避免网格」，skill 标准流恰好产 turnaround grid，**正面冲突**。处理方式是：照 skill 标准流跑，不迁就版式词。测的就是「skill 标准化资产 vs 忠实复刻用户长 brief，整体谁赢」。

**⑤ 防污染**：baseline 臂在项目目录外跑 + transcript grep 审计 + sidecar 标 `produced_by`，挂 R002/R008。

### §5 案例 —— 只留 BEAR-01 一个，走完全程

从「我以为信息越全越保险」到「只压住没全灭」。其余 case 已分散进 §3 §4，不重复。

## D5 · 复原的边界

原始产物图已不可得，展示图为按当时提示词重新生成。约束：

1. **照机制复原，不照结果复原。** v3 那段提示词要还原「四字段逐字拼接导致 `white` 出现六次」这个机制，**不能**直接写 `porcelain`——那是当时的结果，写进提示词就是摆拍
2. 同一参考图、同一模型、同一 seed，只换提示词
3. 配文只写记录里有的，包括没修干净的部分
4. 不出现真实品牌、地名、内部系统 ID
