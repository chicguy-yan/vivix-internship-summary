# ADR-0001 · v3 内容结构与写作口径

- **日期**：2026-08-05
- **状态**：已接受（待执行）
- **影响范围**：`index.html` 全文；后续所有内容改动的基准
- **前一版本**：`v2`（tag）/ `archive/v2`（branch）

---

## 背景

v1 → v2 期间页面从「双链路泳道」改成「六节线性叙事」，配色改莫兰迪，加了左侧目录和轻交互。视觉层已经收敛，但内容层暴露出三个问题：

1. **篇幅超出使用场景。** 本页的实际用途是简历外链，读者停留时间约 2–3 分钟。v2 有 6 章、20 个锚点，读不完。
2. **章节之间有实质重复。** §1 与 §2 都在回答「为什么做这个」；§5 的 case 把 §3 §4 的内容重述了一遍；§6 是前文观点的再总结。
3. **通篇没有实物。** 全靠文字与色块承载，一张 skill 文档截图、一张产出图都没有。对一个「做了什么」的项目复盘，这是硬伤——读者无法验证任何一句话。

---

## 决策

### D1 · 结构由 6 节压缩为 4 节

| 新章节 | 来源 | 承担 |
|---|---|---|
| ① 为什么是这两个 Skill | §1 + §2，压缩约一半 | 竞品判断收成一段；两个痛点；P0 结论 |
| ② 这个 Skill 长什么样 | §3 + 新增图例 | **本页重心**：skill 文档实物 → 四类信息分工 → 产出实物 |
| ③ 凭什么说它有用 | §4 + §5 合并 | 以单个 case 为叙事主线串起三路对照 |
| ④ 学到什么 / 没想明白什么 | §6，砍到 3 条 | 2 条沉淀 + 1 条公开的未解问题 |

**关键改动**：②③ 之间由「设计 / 验证」两个平行块，改为「这是什么 → 凭什么说它有用」的因果推进。第三块不再分头讲方法论和 case，改为**用一个 case 贯穿**。

**代价（已知并接受）**：三路对照的方法论说明会被叙事稀释。取舍理由是——本页读者是面试官而非同行评审，叙事连贯性的收益大于方法论完整性。

**移出**：`自由度与触发方式`（属通用 skill 方法论，与本项目主线无关）、`一句话方法论四联`（与 ② 重复）。

### D2 · 写作口径：具体性优先于工整

v2 的文字工整但抽象。新口径按以下四条执行：

1. **事件带坐标** —— 写「跑完第一批 5 个 case，小熊那张肤色白得不对」，不写「第一轮迭代发现肤色漂移」
2. **保留被推翻的过程** —— 写出当时的错误假设和纠正它的那个观察，而不只给结论
3. **数字带毛边** —— 在口径允许范围内给出原始计数，而非只给百分比
4. **公开一个未解问题** —— 收尾处主动交出一块空白，而不是把边界写成免责声明

**同时约束**：
- 禁用「不是 X，而是 Y」句式（v2 中出现 5 次以上）
- 每节不必都有总结句；允许章节长短不均
- 卡片类内容不追求字数对齐

### D3 · 引入实物图例，并对对照图设硬约束

新增四组图：

| 组 | 位置 | 内容 | 来源 |
|---|---|---|---|
| A | ② 开头 | skill 文档片段（SKILL.md + JSON schema） | 代码截图 |
| B | ② 中部 | JSON → 脚本拼接的 prompt，护栏高亮 | 代码截图 |
| C | ② 结尾 | skill 产出的角色设定图成品 | 生图 |
| D | ③ 主体 | 三路对照产出并排 | 生图 |

**D 组的硬约束（不满足则不放图）**：

1. 三路必须使用**同一张参考图**
2. **同一生图模型、同一 seed**，唯一变量是提示词
3. 不出现公司内部标识或真实素材来源

理由：这组图的全部说服力来自「唯一变量是 skill」。任何一条不满足，它就从证据变成把柄——面试时被追问一句「这三张是同一个模型跑的吗」即失效。

### D4 · 版本保留策略

每次进入结构性改版前，先对当前状态打 tag 并建 archive 分支，再动手。

- `v2` (tag) + `archive/v2` (branch) = 本次改版前的完整还原点
- 线上 `gh-pages` 由 Actions 从 `main` 自动同步；回滚方式为 `git reset --hard v2 && git push -f`

### D5 · 工作文档不进公开仓库

本仓库是简历外链的公开仓库。写作诊断、方案推敲、口径讨论等过程文档一律 gitignore，只保留：

- `index.html` — 成品
- `README.md` — 说明
- `decisions/` — 决策记录（对外可见，措辞按对外标准）

已排除：`SPEC.md`、`PLAN-v3.md`。
